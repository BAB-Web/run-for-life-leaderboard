🔒 โหมดจำลองหน้าเว็บจริง (Standalone HTML/JS แทน Power Pages) กำลังแสดงข้อมูลจำลอง
วิธีที่ 1: โฮสต์บน SharePoint Online คู่กับ SharePoint List (ฟรี 100% ใน Microsoft 365 และข้อมูลไม่รั่วไหลออกนอกบริษัท)
  1. สร้าง SharePoint List ชื่อ VirtualRun โดยมีคอลัมน์: Title (ชื่อนักวิ่ง), TotalKM (Number), OverallStatus (Text), ProfileImage (Text/URL), และ LastUpdate (Date & Time)
  2. ใน Power Automate เปลี่ยนจาก Dataverse มาใช้ Action Create item / Update item ของ SharePoint (เป็น Standard Connector ฟรี)
  3. เปลี่ยนนามสกุลไฟล์ HTML นี้เป็น leaderboard.aspx แล้วอัปโหลดขึ้นโฟลเดอร์ Site Assets หรือ Documents ใน SharePoint ของบริษัท — พนักงานที่ล็อกอิน Microsoft 365 ของบริษัทเท่านั้นจึงจะเปิดดูหน้าเว็บและดึงข้อมูลได้โดยอัตโนมัติ!
วิธีที่ 2: โฮสต์บน Google Apps Script คู่กับ Google Sheets ส่วนตัว (ฟรี 100% ไม่ต้องเปิดไฟล์ Sheet เป็นสาธารณะ)
  1. สร้างไฟล์ Google Sheets (ตั้งค่าแชร์เป็น Private เฉพาะคุณ) สร้างหัวตารางแถวที่ 1: name, totalkm, overallstatus, profileimage, lastupdate
  2. ใน Power Automate ใช้ Google Sheets Connector (ฟรี) อัปเดตข้อมูลนักวิ่งลงใน Sheet
  3. ที่ไฟล์ Google Sheets กดเมนู Extensions > Apps Script แล้ววางโค้ดด้านล่างลงใน Code.gs และนำไฟล์ HTML นี้ไปใส่ในไฟล์ชื่อ index.html จากนั้นกด Deploy > New deployment > Web app:
function doGet() {
  return HtmlService.createHtmlOutputFromFile('index')
    .setTitle('🏆 Run for Life — Leaderboard')
    .setXFrameOptionsMode(HtmlService.XFrameOptionsMode.ALLOWALL);
}

function getRunnersData() {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];
  var rows = sheet.getDataRange().getValues();
  var headers = rows.shift();
  return rows.map(function(r) {
    return {
      name: String(r[0] || ''),
      totalkm: parseFloat(r[1]) || 0,
      overallstatus: String(r[2] || ''),
      profileimage: String(r[3] || ''),
      lastupdate: r[4] ? new Date(r[4]).toISOString() : ''
    };
  });
}
